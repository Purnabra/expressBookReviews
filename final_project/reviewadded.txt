Test 1: User 1 adds a review

Login command:

curl -c user1-cookies.txt --request POST localhost:5000/customer/login --header "
Content-Type":"application/json" --data '{"username":"alice","password":"pass@123"}'


Login output:
{"message":"You Are Logged In!!"}


Review command:

curl -b user1-cookies.txt --request PUT localhost:5000/customer/auth/review/1?rev
iew=This%20book%20is%20excellent

Review output:
{"message":"Review Added Successfully!!"}


check Review command:

curl localhost:5000/review/1


check Review output:


{"alice":"This book is excellent"}
